Movie Ticket Booking System - Project Guide

Second Year Diploma / Degree Computer Engineering Micro-Project

Architecture & Technology Stack

  • Backend: Pure Java (Core Java 17, `com.sun.net.httpserver.HttpServer`, Thread Pool Executor, Zero external Maven dependencies required).
  • REST API: Full JSON endpoints for Authentication, Movie Catalog, Showtimes, Seat Lock, Booking, and Cancellation.
  • Storage Engine: JSON Persistence Database (`data/database.json`) with synchronized thread-safe file I/O.
  • Frontend: Modern Responsive Single Page Application (HTML5, Modern CSS3 Flexbox/Grid, Vanilla JavaScript Fetch API).
  • Payment Simulation: Realistic Dummy Payment Gateway with UPI QR, Card validation, and Net Banking.

Key Java Concepts Demonstrated for Viva

  • Object-Oriented Programming (OOP): Encapsulation (User, Movie, Showtime, Booking models), Inheritance, Polymorphism.
  • Concurrency & Multithreading: Multi-threaded HTTP server handling simultaneous requests; `synchronized` seat reservation preventing double booking (race conditions).
  • Data Structures: `ConcurrentHashMap`, `LinkedHashSet` for ordered seat sets, `ArrayList`, `Comparator`.
  • File I/O & Serialization: Persistent JSON serialization & parsing without bulky third-party libraries.
